Open Source

Repayment Assistance Advisor

.NET 9 · Angular 19 · Claude · Azure

Explains student loan repayment assistance decisions in plain language, with every statement traceable to the policy clause behind it. Eligibility is decided by a pure, deterministic engine in C#; the language model only rewrites that result for a human reader — it cannot see the borrower record and has no path to change an outcome. In regulated lending, an explanation a model invented is worse than none, because it is confidently wrong in a way nobody can audit.
