Repayment Assistance Advisor

.NET 9 · Angular 19 · Claude · Azure

Explains student loan repayment assistance decisions in plain language, with every statement traceable to the policy clause behind it. Eligibility is decided by a pure, deterministic engine in C#; the language model only rewrites that result for a human reader — it cannot see the borrower record and has no path to change an outcome. In regulated lending, an explanation a model invented is worse than none, because it is confidently wrong in a way nobody can audit.

Build Log Notes

Notes from building the Repayment Assistance Advisor — the decisions worth writing down, and the things that only broke once they were deployed.

Why the model is not allowed to decide anything

The eligibility engine is pure C# and the language model never touches it. It receives a decision that has already been made, plus the policy clauses behind it, and rewrites that for a human reader. In regulated lending an explanation the model invented is worse than no explanation, because it is confidently wrong in a way nobody can audit. Keeping the decision deterministic is also what makes it testable: same inputs, same answer, every time.

A bug that only existed in production

Every dollar figure rendered as ¤2,800.00 once deployed, and as $2,800.00 on my machine. The :C format specifier follows the ambient culture, and a Linux container with no LANG set falls back to the invariant culture and its generic currency sign. It passed every local test. The fix was to stop inheriting formatting from the host, and the regression test now asserts the output is identical under five cultures.

Picking a host is mostly picking which limit you can live with

Netlify cannot run ASP.NET Core at all, so the client and the API had to be split. Azure needed an account I could not create; Koyeb closed its free tier to new signups the week I tried it. Render works, at the cost of sleeping after fifteen minutes. The container starts in about two seconds and holds 24 MB, so the wake is short — and a scheduled ping keeps it from happening at all.
